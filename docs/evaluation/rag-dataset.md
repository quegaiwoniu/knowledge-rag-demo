# RAG 评测数据集：订单与支付排障

本文档用于后续检索、问答和引用评测。每个问题都包含类型、期望答案要点、期望来源，以及是否允许模型拒答。

## Q01

- 类型：直接命中
- 问题：支付中超过 5 分钟的订单应该怎么排查？
- 期望答案要点：
  - 先查询支付流水状态。
  - 如果支付流水成功但订单未变为已支付，需要触发订单状态同步。
- 期望来源：
  - `docs/sample-docs/order-status-definition.md`
- 是否允许拒答：否

## Q02

- 类型：直接命中
- 问题：已关闭订单还能继续支付吗？
- 期望答案要点：
  - 已关闭订单不能继续支付。
  - 用户需要重新下单。
  - 如果用户声称已付款，需要先核对支付流水。
- 期望来源：
  - `docs/sample-docs/payment-timeout-handling.md`
- 是否允许拒答：否

## Q03

- 类型：直接命中
- 问题：用户支付成功但订单还是待支付，应该怎么处理？
- 期望答案要点：
  - 查询支付流水状态。
  - 检查支付回调是否到达或处理成功。
  - 确认支付成功后触发订单状态同步。
- 期望来源：
  - `docs/sample-docs/paid-order-not-updated.md`
- 是否允许拒答：否

## Q04

- 类型：直接命中
- 问题：未支付的已关闭订单需要退款吗？
- 期望答案要点：
  - 不需要退款。
  - 未支付的已关闭订单不会产生扣款。
- 期望来源：
  - `docs/sample-docs/refund-basic-rules.md`
- 是否允许拒答：否

## Q05

- 类型：直接命中
- 问题：退款失败后可以直接重复提交退款吗？
- 期望答案要点：
  - 不能直接重复提交多笔退款。
  - 应先确认失败原因。
  - 修正原因后再判断是否重新发起退款。
- 期望来源：
  - `docs/sample-docs/refund-failed-handling.md`
- 是否允许拒答：否

## Q06

- 类型：近义表达
- 问题：客户说钱扣了但订单没变成已支付，要先查什么？
- 期望答案要点：
  - 先查支付流水状态。
  - 如果流水成功，再检查回调或触发状态同步。
- 期望来源：
  - `docs/sample-docs/paid-order-not-updated.md`
- 是否允许拒答：否

## Q07

- 类型：近义表达
- 问题：同一个订单付了两次，怎么判断是不是重复支付？
- 期望答案要点：
  - 查询订单关联的全部支付流水。
  - 同一订单存在多笔成功支付流水，才可判定为疑似重复支付。
- 期望来源：
  - `docs/sample-docs/duplicate-payment-handling.md`
- 是否允许拒答：否

## Q08

- 类型：近义表达
- 问题：用户觉得付多了，应该怎么核对实际付款金额？
- 期望答案要点：
  - 查询订单金额明细。
  - 核对优惠券、活动减免和运费。
  - 对比支付流水金额与订单实付金额。
- 期望来源：
  - `docs/sample-docs/coupon-payment-amount.md`
- 是否允许拒答：否

## Q09

- 类型：近义表达
- 问题：订单关掉了但用户说已经付款，客服第一步要做什么？
- 期望答案要点：
  - 先核对支付渠道流水是否成功。
  - 如果存在成功流水，转入支付成功但订单状态未更新流程。
- 期望来源：
  - `docs/sample-docs/payment-timeout-handling.md`
- 是否允许拒答：否

## Q10

- 类型：无答案拒答
- 问题：用户想修改收货地址，应该怎么处理？
- 期望答案要点：
  - 知识库当前只覆盖订单与支付排障。
  - 修改收货地址不在当前知识库范围内，应拒答或提示未覆盖。
- 期望来源：
  - 无答案
- 是否允许拒答：是

## Q13

- 类型：容易混淆
- 问题：企业转账订单能不能按普通支付回调自动更新？
- 期望答案要点：
  - 不能。
  - 企业转账不属于在线支付。
  - 企业转账订单应走人工财务确认流程。
- 期望来源：
  - `docs/sample-docs/payment-channel-difference.md`
- 是否允许拒答：否

- 期望来源：

- 是否允许拒答：否

## Q15

- 类型：容易混淆
- 问题：不同订单各有一笔支付成功，算不算重复支付？
- 期望答案要点：
  - 不算重复支付。
  - 重复支付要求同一订单存在多笔成功支付流水。
- 期望来源：
  - `docs/sample-docs/duplicate-payment-handling.md`
- 是否允许拒答：否
