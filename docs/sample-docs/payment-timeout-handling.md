# 支付超时订单处理规范

## 超时定义

订单创建后 30 分钟内未完成支付，系统会自动关闭订单。订单关闭后，原订单不能继续支付，用户需要重新下单。关闭订单如果没有成功支付流水，不会产生扣款。

## 用户提示规则

当用户咨询已关闭订单是否还能支付时，客服应明确告知该订单不能继续支付，需要重新创建订单。如果用户表示已经付款，应先核对支付渠道流水，不能仅凭用户描述判断扣款成功。

## 排障步骤

1. 检查订单创建时间、关闭时间和当前订单状态。
2. 查询支付渠道流水是否存在成功记录。
3. 如果没有成功流水，引导用户重新下单。
4. 如果存在成功流水，转入“支付成功但订单状态未更新”排障流程。

## 可引用结论

已关闭订单不能继续支付；如用户已付款，应先核对支付流水是否成功。
