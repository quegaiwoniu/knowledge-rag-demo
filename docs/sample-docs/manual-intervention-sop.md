# 订单支付异常人工介入 SOP

## 人工介入条件

涉及真实扣款、重复支付、退款失败、支付流水与订单状态不一致的异常，需要人工介入并保留处理记录。人工介入不是优先手段，只有系统自动同步或标准流程无法完成时才使用。

## 处理记录要求

人工修改订单状态前，必须有支付流水或财务确认作为依据。禁止仅凭用户截图直接修改订单支付状态。处理记录应包含订单号、用户 ID、支付流水号、处理原因、操作人和处理时间。

## 排障步骤

1. 收集订单号、用户 ID、支付流水号等必要信息。
2. 核对系统订单状态和渠道交易状态。
3. 记录处理原因、操作人和处理时间。
4. 完成人工处理后通知用户处理结果。

## 可引用结论

人工修改订单状态前，必须以支付流水或财务确认为依据，不能仅凭用户截图处理。
