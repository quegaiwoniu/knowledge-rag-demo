# 重复支付识别与处理规范

## 重复支付定义

同一订单出现两笔或两笔以上成功支付流水，视为疑似重复支付。不同订单分别存在成功支付流水，不属于重复支付，应按各自订单独立处理。

## 判断依据

判断重复支付时，应以订单号和支付流水为准。用户提供的付款截图只能作为辅助信息，不能替代系统流水。重复支付确认后，需要保留一笔有效支付，其他多余成功流水按异常支付退款处理。

## 排障步骤

1. 查询订单关联的全部支付流水。
2. 判断是否存在同一订单多笔成功支付。
3. 保留最早成功或业务确认有效的一笔支付。
4. 对多余成功流水发起异常退款流程。

## 可引用结论

同一订单存在多笔成功支付流水时，才可判定为疑似重复支付。
