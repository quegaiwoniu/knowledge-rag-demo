# 优惠券与实付金额核对说明

## 金额组成

订单实付金额 = 商品金额 - 优惠券金额 - 活动减免金额 + 运费。用户最终支付金额应与订单实付金额一致。支付流水金额是判断用户实际扣款金额的重要依据。

## 常见疑问

用户认为支付金额偏高时，常见原因包括优惠券未成功锁定、活动减免条件不满足、运费发生变化。优惠券抵扣失败时，订单实付金额会高于用户预期。

## 排障步骤

1. 查询订单金额明细，确认商品金额、优惠券金额、活动减免金额和运费。
2. 核对优惠券是否成功锁定和使用。
3. 检查活动减免是否满足条件。
4. 对比支付流水金额与订单实付金额是否一致。

## 可引用结论

核对支付金额时，应以订单实付金额和支付流水金额是否一致为准。
