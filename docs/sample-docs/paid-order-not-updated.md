# 支付成功但订单状态未更新排障手册

## 问题现象

用户反馈支付已经成功，但订单页面仍显示 `待支付` 或 `支付中`。这类问题通常发生在支付渠道回调延迟、支付回调处理失败、订单系统状态同步任务异常等场景。

## 常见原因

如果支付渠道流水显示成功，订单系统应以支付流水为准进行状态同步。支付成功但订单未更新时，不能让用户重复支付，也不能直接关闭原订单。

## 排障步骤

1. 查询支付流水状态，确认渠道是否返回支付成功。
2. 检查支付回调是否到达订单系统，以及回调处理是否成功。
3. 如果回调失败，重新拉取渠道交易结果。
4. 确认支付成功后，触发订单状态同步，将订单更新为 `已支付`。

## 可引用结论

当支付流水显示成功但订单未更新时，应以支付流水为准触发订单状态同步。
