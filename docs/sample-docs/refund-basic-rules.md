# 退款基础规则说明

## 退款适用场景

只有 `已支付` 且未完成最终履约的订单才允许发起退款。已关闭但未支付的订单不会产生扣款，因此不需要退款。订单如果已经完成最终履约，需要根据业务售后规则判断是否允许退款。

## 退款时效

原路退款一般在 1 到 3 个工作日到账。具体到账时间可能受银行、支付渠道和节假日影响。客服不应承诺固定到账分钟数。

## 排障步骤

1. 确认订单是否已经支付成功。
2. 检查订单是否进入不可退款状态。
3. 查询退款单状态和退款渠道流水。
4. 如果退款超过预计时效仍未到账，需要转人工财务核查。

## 可引用结论

未支付的已关闭订单不会产生扣款，因此不需要发起退款。
