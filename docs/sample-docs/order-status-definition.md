# 订单状态定义与流转说明

## 订单状态说明

订单状态用于描述用户从下单到履约完成之间的业务进度。`待支付` 表示订单已创建但用户尚未完成支付，系统默认保留 30 分钟；`支付中` 表示支付渠道已受理请求，但订单系统还没有收到最终支付结果；`已支付` 表示支付成功且订单金额已入账，可以进入后续履约流程。

## 常见状态流转

正常情况下，订单会从 `待支付` 流转到 `支付中`，再流转到 `已支付`。如果订单创建后 30 分钟内没有完成支付，系统会自动关闭订单。支付渠道回调延迟时，订单可能短时间停留在 `支付中`。

## 排障步骤

1. 先查询订单当前状态，确认是 `待支付`、`支付中` 还是 `已支付`。
2. 如果订单处于 `支付中` 超过 5 分钟，优先查询支付流水状态。
3. 如果支付流水成功但订单仍未变为 `已支付`，需要触发订单状态同步。

## 可引用结论

支付中超过 5 分钟的订单，应优先核对支付流水，再决定是否触发订单状态同步。
