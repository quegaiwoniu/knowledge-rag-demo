# 不同支付渠道差异说明

## 渠道类型

系统支持微信、支付宝、银行卡等在线支付渠道。企业转账属于线下或半线下财务确认方式，不属于普通在线支付，不能按普通支付回调流程处理。

## 到账与回调差异

微信、支付宝、银行卡支付的回调时延可能不同。银行卡支付偶尔会出现渠道结果延迟，需要等待渠道最终状态。渠道状态不明确时，不应立即人工改为支付成功。

## 排障步骤

1. 确认订单使用的支付渠道。
2. 查询对应渠道的交易状态。
3. 判断是否存在渠道回调延迟或最终状态未返回。
4. 对企业转账订单，走人工财务确认流程。

## 可引用结论

企业转账不属于在线支付，不能按普通支付回调流程自动更新订单状态。
