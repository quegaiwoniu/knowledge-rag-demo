# 退款失败处理流程

## 退款失败原因

退款失败常见原因包括原支付账户异常、支付渠道拒绝、退款金额超过可退金额、原交易已超过渠道支持的退款期限。退款失败不代表用户一定没有退款资格，需要结合失败原因判断。

## 处理原则

退款失败后不能直接重复提交多笔退款，应先确认失败原因。对于渠道明确返回失败的退款，可以修正原因后重新发起退款；对于渠道状态不明确的退款，需要等待最终结果或转人工财务处理。

## 排障步骤

1. 查询退款单失败原因和渠道返回码。
2. 核对订单可退金额、原支付渠道和原支付账户状态。
3. 判断是否允许重新发起退款。
4. 如果渠道异常持续存在，转人工财务处理，并记录处理原因。

## 可引用结论

退款失败后应先确认失败原因，不能直接重复提交多笔退款。
